# leetcode_problems

# 🚀 Daily LeetCode Practice

This repository contains my **daily LeetCode problem-solving journey**, where I consistently practice Data Structures and Algorithms (DSA) and push solutions to GitHub.

The goal is to improve **problem-solving skills**, **coding efficiency**, and **interview readiness** through disciplined daily practice.

---

## 📌 Objectives

- Solve LeetCode problems **daily**
- Strengthen understanding of **DSA fundamentals**
- Maintain a **public, consistent coding streak**
- Prepare for **technical interviews & coding assessments**

---

## 🧠 Topics Covered

- Arrays & Strings  
- Linked Lists  
- Stacks & Queues  
- Hashing  
- Two Pointers  
- Sliding Window  
- Recursion & Backtracking  
- Binary Search  
- Trees & Binary Trees  
- Binary Search Trees  
- Graphs (BFS / DFS)
